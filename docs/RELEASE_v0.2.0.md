# v0.2.0 更新说明

发布日期：2026-06-05

## 新功能

- **自定义播放倍速** — 新增 `--speed` 参数，支持 0.5x ~ 3.0x 倍速（默认 1.0）。倍速仅影响心跳等待时间，不改变平台进度数据。
  ```bash
  haiqikeji -n <账号> -p <密码> --speed 2.0 --skip
  ```

## 修复

- **中断时正确结束学习会话** — 按 Ctrl+C 中断刷课时，会先发送当前进度心跳并结束会话，避免会话残留。

- 安装说明默认使用清华 PyPI 镜像源
- 更新克隆地址和使用说明
- 新增 `--speed` 参数文档（README、CLAUDE.md、流程文档）
